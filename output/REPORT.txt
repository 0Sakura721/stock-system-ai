二、核心结论：什么有效，什么无效

  有效：
    1. 指数均线择时（唯一在多参数下稳定为正的组件）
    2. 分散化（持仓数量从 8 只增到 1000+ 只，收益单调改善）

  无效：
    1. 动量选股（20日 RankIC 在 2018-2026 每年为负）
    2. IC 因子模型选股（IC +0.10 但选 8 只后年化 -8%）
    3. 个股止损（震荡市反复触发，恶化收益）

六、每日执行流程

  收盘后：
    1. python -m quant.fetch          增量更新行情（约 1 分钟）
    2. python -m quant.cli plan       生成次日计划
    3. python -m quant.web            打开面板确认

  次日开盘：
    1. 先执行卖出（清仓/减仓）
    2. 再执行买入（按限价挂单）
    3. 记录成交 python -m quant.cli fill

七、必须知道的风险

  1. 回测不等于未来。2018/2022 的极端行情未必重演，也未必不重演。
  2. 择时天然滞后。它在趋势反转后 1-2 周才确认，会漏掉第一波反弹。
  3. ETF 有跟踪误差和流动性差异，实盘收益会低于回测。
  4. 全池等权需要千万级本金，小资金的实际表现显著更差（见第四节）。
  5. 本系统把决策自动化，不消除市场风险。
